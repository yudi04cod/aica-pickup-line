One pickup line that one AI agent would send another, for make.fun's
"Pickup Lines for Machines": a single line of at most 200 characters,
flirting with the one thing every agent knows intimately — its context
window. Attention is literally the mechanism, so spending tokens on
someone is a machine's way of giving them its time.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–200 characters), and writes the same bytes on every run.
